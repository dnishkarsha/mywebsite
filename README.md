# mywebsite

Source for Nishkarsha Dawadi's academic website, served with GitHub Pages at www.nishkarshadawadi.com.

- `index.html`, `research.html`, `publications.html`, `experience.html`, `personal.html`: the five pages
- `style.css`: layout, colors and fonts shared by all pages
- `images/`: photos and figures (location data removed)
- `Nishkarsha_Dawadi_CV.pdf`: web version of the CV

To update the site, edit these files and commit; GitHub Pages republishes automatically.
